# Reporting serious errors

Most mistakes in the index should be reported as a normal [correction issue](../../issues/new?template=correction.yml).

Report privately instead if an error could lead someone to deploy a model unsafely or unlawfully, for example a licence wrongly shown as allowing commercial use, or a missing safety limitation. Use GitHub's private vulnerability reporting on this repository ("Report a vulnerability" under the Security tab). We aim to respond within 7 days.
