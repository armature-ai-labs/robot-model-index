# Governance

The Robot Model Index is maintained by Armature AI Labs.

- **Decisions.** The lead maintainer makes final decisions on the schema, data rules and releases. Proposals start as GitHub issues so anyone can comment.
- **Verification.** Only a maintainer can mark an entry `verified`, after checking every claim against its sources.
- **New maintainers.** Contributors with a sustained record of accurate, well-sourced pull requests may be invited to become maintainers.
- **Corrections win.** A well-sourced correction is merged quickly, even if it contradicts an earlier entry.
